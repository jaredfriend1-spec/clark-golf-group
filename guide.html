For the Admins

The app does the heavy lifting. You just drag, drop, and push the buttons.

★ Signing In as Admin

Admins sign in exactly like members — register your phone number using “Need to set up your login?” on the landing page, then sign in with your last 4 digits. The app recognises your admin status automatically and unlocks additional tabs. No separate password needed.

Admin Roles — Three Levels

⭐ Master Admin (Jared) — full access to everything: all app tabs, the Stats dashboard, and the Admin Portal. Cannot be changed by other admins.

🛡️ Super Admin (Clark, etc.) — sees the full Admin tab, Email tab, and all player tabs. Can manage days, teams, roster, notes, and score games. Gets access to the Admin Portal with a separate password.

📊 Scoring Admin — sees only the player tabs (Week, Teams, History, Standings, Attend) plus the Score tab unlocked. Can enter scores and publish results to history. Cannot see the Admin tab, Email tab, or Stats. Designed for week-to-week scoring help — easy to turn on and off.

Admins must register first

Before deploying to members, make sure all admins have registered their phone numbers. Otherwise you won’t be able to access admin features after deploy.

Two sign-up buttons for admins

On the Week tab, admins see two buttons at the bottom of each day card instead of the usual one:

+ Sign me up — green, instantly pre-fills your own name (same fast experience as a regular member).
+ Sign up someone — blue, opens the full roster picker so you can sign up any player on their behalf, set their tees and HCP, add a tee preference, or create a match pairing for them.

Managing admin roles

Admin roles are managed from the Admin Portal (portal.html) — a separate tool for group management. The Master Admin can add or remove admins, and change anyone between Super Admin and Scoring Admin with a single dropdown. See the Admin Portal section below for details.

🔒 Master Admin protection

The Master Admin (Jared) is flagged in Firebase. Their phone number and admin status are completely locked in the app UI — no other admin can change them. The only way to update the Master Admin’s phone number is through self-registration on the landing page, which requires physical access to their phone. This prevents anyone from accidentally or intentionally locking out the core admin.

● Quick note on navigation

The bottom tab bar uses colored icons to help you find things fast — each tab has its own color when active: Week (green), Teams (blue), Score (amber), History (purple), Email (cyan), Admin (orange).

Scoring Admins see the same player tabs as members, but with the Score tab always unlocked. They do not see the Email, Admin, or Stats tabs.

The auto-generate algorithm checks your round history and avoids putting the same players together week after week — while keeping teams balanced by handicap. Gets smarter the more rounds you play.

A small ✕ button appears on each player row in edit mode — tap it to remove a player from a team. They drop instantly into the gold Unassigned Players banner below, where you can place them in any other team with one tap.

Slots always re-sort automatically

After any drag, move, or edit, the app instantly re-sorts each team by handicap and reassigns A/B/C/D correctly. You can never accidentally end up with a 5 HCP player in slot D and a 22 HCP in slot A.

Delete cleans up automatically

Deleting a player from the roster automatically removes their PIN, email, and admin flag from Firebase. No manual cleanup needed.

Admin Portal

A separate management tool at portal.html for running the group behind the scenes. Only the Master Admin and Super Admins with a portal password can access it.

1 What’s in the Portal?

The portal has its own set of tabs, separate from the main app:

Dashboard — active days, player counts, tournament pot, system health check, Firebase inspector (Master only), activity log, and login log with clear function.

Week — manage days and sign-ups, view day checklists, edit weekly notes and announcements. End Week requires typing “END” to confirm.

Email — same email builder as the main app with formatted preview, Copy Formatted, and Copy Plain Text.

Roster — segmented into Active (has PIN), Inactive (no PIN), and Hidden players. Full edit: name, email, tee, handicap, PIN status, reset PIN.

Access — manage admin roles. Add admins, change between Super Admin and Scoring Admin with a dropdown, remove access. Role summary cards show counts at a glance.

History — view and manage completed rounds. Delete requires typing “DELETE”. Deleted rounds go to trash (recoverable from main app).

Attend — log rounds, edit attendance, view standings. Same data model as the main app’s attendance.

Settings — Master only. Firebase auth setup, tournament fund balance, master password, sign out.

2 Managing Admin Roles

Go to the Access tab in the portal. Three role summary cards show how many of each type you have.

To add an admin: Search for a player in the “Add Admin” card → tap “+ Add as Scoring Admin.” They appear in the Current Admins list below.

To change a role: Each admin has their own dropdown. Tap it to switch between 🛡️ Super Admin and 📊 Scoring Admin. Only that person changes — nobody else is affected.

To remove: Tap the “✕ Remove” button on their row. Confirm in the popup. Their PIN and roster entry are unaffected.

New admins default to Scoring Admin

When you add someone, they start as a Scoring Admin (score entry only). You have to actively promote them to Super Admin if you want them to have full access.

3 Activity & Login Logs

The Dashboard shows two log cards (expanded by default):

Activity Log — sign-ups, removals, team publishes, day setup, new weeks, roster adds, match requests. Color-coded by event type with relative timestamps.

Login Log — member and admin logins, self-registrations. Summary cards show member vs admin login counts. Master can clear login history (type DELETE to confirm).

4 Accessing the Portal

Go to clark-golf-group-two.vercel.app/portal.html. Enter the master password to sign in. Super Admins will need a separate portal password (coming soon).

Portal is separate from the main app

Changes made in the portal (roles, roster, attendance) write to the same Firebase database as the main app. Everything stays in sync — add an admin in the portal and they see their new access in the main app immediately.

Season Attendance

A separate tracker that follows every player across the whole season — rounds played and the year-end tournament pot.

1 Automatic Tracking

Every time a round is moved to history or the week is closed out, player names are automatically pushed to attendance. No duplicate counting — if the same date is pushed twice, it replaces rather than duplicates.

2 Season Standings

A searchable leaderboard ranked by rounds played. Tap any player to see every date they played. Gold, silver, and bronze badges for the top three.

3 Year-End Tournament Pot

Tracks $1 per player per round automatically, always visible in the header.

4 Admin Controls

Admins can log rounds manually — pick a date, select players from the full roster, add guests by name. Edit or delete existing rounds. Import attendance data from CSV for bulk loading.

5 End Season & Archive

At year-end, archive the entire season. Archived seasons stay viewable from pill buttons in the header. A separate Clear All Data option permanently deletes everything — requires typing “DELETE” to confirm.
